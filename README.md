
# Telegram Service

Сервис для управления множественными соединениями с Telegram через gRPC API.

## Требования

- Go 1.26+
- Protobuf compiler
- Telegram API credentials (api_id и api_hash)

## Установка

1. Клонируйте репозиторий:
```bash
git clone git@github.com:JettaJac/telegramService.git
cd telegram-service
